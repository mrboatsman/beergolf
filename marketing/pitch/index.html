Självjusterande handikapp

  • Alla startar på HCP 36 med nytt grönt kort

  • Bra runda → ner. Tung kväll → upp. Systemet dömer, inte kompisarna.
  • Trendgraf på dashboarden — se säsongens resa

Turneringar = välgörenhet ❤️

  • Captain skapar: välgörenhetsmål, anmälningsavgift, prisupplägg deklareras innan öppning
  • Livscykel: utkast → öppen → avslutad — regler låses vid öppning
  • Två format: slagspel (netto-leaderboard) eller cup (slumpad lottning, matchstege)
  • Synlighet: öppen för klubben, sluten (inbjudan) eller helt publik

Varje krona redovisad

Publika turneringar — gäster välkomna

  • Publik sida /t/[slug] — inget konto behövs
  • Gästen anmäler sig, betalar via Stripe, självdeklarerar HCP
  • Personlig tokenlänk för egen scoreinmatning
  • Gästresultat rör aldrig medlemmarnas handikapp eller rundhistorik
  • Publika vyn visar siffror — aldrig e-postadresser

Resan i en bild

1Engångskoden 🎟️

  • Admin skapar fristående engångskoder — ingen e-post krävs i förväg
  • Koden lämnas över personligen: på klubbkvällen, i handen, som sig bör
  • En kod = ett medlemskap. Förbrukad kod syns i admin med vem den blev
  • Sök bland koder, se vem varje kod blev — full spårbarhet
/admin

2Registrering på /join 📝

  • Aspiranten går till /join och anger sin kod
  • Namn + e-post + lösenord — klart på en minut
  • Kontot skapas med status aspirant
  • Koden förbrukas i samma ögonblick — kan aldrig återanvändas

3Aspirantläget 🔒

  • Aspiranten ser bara Grönt Kort och Teoriprov i menyn
  • Alla andra sidor → omdirigering, hårt på servern — ingen kan smyga runt
  • Aspiranter kan inte läggas på coasters — inget spel utan kort
  • Fokus: klara certifieringen. Sen öppnas klubben.

4Certifieringens tre delar 🎓

📖 1 · Teoriprov Quiz med slumpad frågeordning, rättas på servern. Godkänt vid ≥ 80 %. Underkänd? Facit visas — och hedersknappen ”Jag har lärt mig läxan” finns för den ödmjuke.
🏌️ 2 · Praktiskt prov Provslingan spelas inför en certifierad medlem som examinerar. Omdöme skrivs och bevis krävs — minst en bild eller film. Inget bevis? Rekonstruera situationen.
🎩 3 · Etikett & hänsyn Faddern bedömer uppförandet löpande och godkänner via bekräftelsemodal med klubbens etikettkriterier. Aspiranten ser samma kriterier — inga överraskningar.

Vilken certifierad medlem som helst kan examinera — inte bara de med rollen fadder

5Grönt kort — automatiskt 🟩

När tredje delen godkänns händer allt av sig självt:

  • Nästa lediga medlemsnummer utfärdas
  • Status → aktiv, roll → member
  • Ingångshandicap HCP 36
  • Alla dörrar öppnas: coasters, leaderboard, turneringar

Certifieringsunderlaget (provhistorik, omdöme, bevis) följer med profilen för alltid.

…och examinatorn då?

  • Den som godkänner en aspirant uppgraderas automatiskt member → fadder
  • Captain och admin behåller förstås sin roll
  • Relationen skrivs in i fadderträdet — för alltid
  • Så växer klubben: varje medlem kan föra traditionen vidare

Admin & GDPR 🔒

/admin — medlemmar, koder & kontoåtgärder
  • Invalskoder och direktskapade medlemmar på ett ställe
  • Återställ lösenord — engångslösenord, tvingat byte
  • Inaktivera konto → levande sessioner dödas direkt
  • Anonymisera (GDPR) — oåterkalleligt, men spelhistoriken behålls som klubbstatistik
  • Paginerat och sökbart — testat med 1000+ medlemmar
